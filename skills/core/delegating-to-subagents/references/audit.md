# Аудит документа против источника правды

«Пройдись по документу и найди несоответствия» на длинном тексте (модель на тысячу строк, регламент, свод правил) — работа для 4–6 читателей, а не для одного прохода: контекст одного потока не вмещает весь документ вместе с эталоном.

- **Делить по номерам разделов и диапазонам строк**, номера брать из `grep -n '^## '`: «разделы 6–15, строки 376–720». Пересечение диапазонов не допускать, иначе один и тот же дефект придёт из двух отчётов и слияние превратится в сверку.
- **Эталон — отдельный файл, а не пересказ в брифе.** В `context`: путь к странице истин («при расхождении права она»), свой диапазон, 2–4 связанные заметки, которые этот диапазон дублирует. Ключевые правила всё равно переписать в брифе списком: до файла ребёнок может не дойти, а противоречие с пересказом в задании он поймает.
- **Формат отчёта один для всех потоков**, иначе слияние дороже аудита: таблица `# | Строка | Цитата (до 120 символов, дословно) | Проблема | Противоречит | Предложение` плюс разделы «внутренние противоречия» и «требует решения владельца». Каждый пишет свой файл (`A.md`…`E.md`) и возвращает путь с числом находок — по числу родитель видит, не сдался ли поток на первом разделе.
- **Дословная цитата и номер строки — обязательны.** Без них находку нельзя ни проверить, ни применить: пересказ «тут написано про локальность» указывает не туда, а строка нужна, чтобы отличить два похожих абзаца.
- **Дети только читают.** В брифе: ничего не править, не коммитить, git не трогать; спорное — в раздел «требует решения владельца», а не в правку. Иначе ребёнок «улучшает» документ по своему вкусу, и родитель разбирает не находки, а чужую редактуру.
- **Проверять цитаты до правок.** Каждую строку из отчёта сверить `grep -F` по файлу: ребёнок читал копию, цитата может быть из прежней версии, а номер строки — сдвинут. Цитаты нет в файле — это **не находка**: выбрасывать, а не восстанавливать по смыслу отчёта (часть пунктов уже закрыта предыдущими проходами или ребёнок пересказал соседнюю заметку по памяти). Затем правки пачкой `assert text.count(old) == 1` (приём: список пар «было → стало» и применение с проверкой числа вхождений); несовпадение цитаты — не ошибка ребёнка, а сигнал, что документ уже правили. В отчёте владельцу давать два числа — сколько находок принято и сколько отклонено с причиной, иначе 70 пунктов выглядят как 70 обязательных правок.
- **Разделять три исхода в отчёте владельцу:** исправлено (с цитатой «было → стало»), решает владелец (с рекомендуемым вариантом первым), отклонено как вкусовщина.
