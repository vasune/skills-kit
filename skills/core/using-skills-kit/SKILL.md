# Дисциплина навыков skills-kit

Каталог навыков в системном промпте — не справочник, который листают при желании, а обязательный шаг перед работой. Навык, загруженный после того, как решение уже принято, бесполезен: он объясняет, как делать, а не оправдывает сделанное.

## Когда открывать

- Начало любой задачи: сначала каталог навыков, потом действия.
- Нужно решить, какой навык открывать под задачу.
- Навык открыт, но непонятно, как встроить его в работу.

## Правило

1. **Перед действием** — включая чтение файлов и разведку — сверить задачу с каталогом навыков.
2. **Задача попадает под триггер — навык загружается** (инструментом хоста, точным именем) до ответа. Сомнение «подойдёт или нет» решается по описанию и `INDEX.md`, а не загрузкой «на всякий случай».
3. **Объявить:** «Использую `<навык>` для `<цели>`».
4. **Если у навыка чек-лист** — завести todo по пунктам и идти по нему.
5. **После работы** — проверить, не надо ли обновить навык (`skill-library-maintenance`): урок, который не записан, потерян.

## Приоритет

Процессные навыки идут первыми — они задают подход, предметные выполняют:

| Ситуация | Первый навык |
|---|---|
| «Давай сделаем X», цель не ясна | `brainstorming` |
| Задача больше одного шага | `plan` |
| Есть утверждённый план | `subagent-driven-development` |
| «Готово / проходит / исправлено» | `verification-before-completion` |
| Перед коммитом или PR | `requesting-code-review` |
| Баг непонятен | `systematic-debugging` |
| Пишется логика | `test-driven-development` |
| Задача делится на куски | `delegating-to-subagents` |
| Нужен готовый навык или промпт | `skill-sourcing` |

## Красные флаги: это рационализация

| Мысль | Реальность |
|---|---|
| «Это простой вопрос» | Вопрос — тоже задача. Проверь навык. |
| «Сначала соберу контекст» | Навык говорит, как собирать контекст. |
| «Я помню этот навык» | Навыки меняются. Читай текущую версию. |
| «Тут не нужен формальный подход» | Если навык есть — он и есть подход. |
| «Уже поздно, я в середине» | Проверь сейчас, до следующего шага. |
| «Навык не подойдёт» | Сверь триггер: совпал — загрузи, не совпал — не трать контекст. |

## Где каталог

- В системном промпте — список навыков с триггерами.
- Полный каталог с уровнями и «когда открывать» — `INDEX.md` в репозитории `skills-kit`.
- Ничего не нашлось — `skill-sourcing` (поиск готового) или `skill-library-maintenance` (создать свой).

## Стоимость

Тело навыка — от 6 до 22 КБ, и оно уезжает в контекст целиком при загрузке. Норма — один-два навыка под задачу; пять — шум, в котором теряются детали. Поэтому сначала триггер и описание, потом загрузка: сверить задачу с каталогом дешевле, чем открыть навык, который не подошёл.

## Исключение: субагент

Если ты запущен с конкретным брифом (делегированная задача) — не ищи навыки заново: следуй брифу и правилам родителя. Дисциплина относится к главной сессии; ребёнку навыки подменяют задание.

## Как это попадает в первую сессию

Навык сам себя не загрузит, поэтому правило дублируется в стартовую инструкцию хоста — файл, который читается в начале каждой сессии. Какой это файл, где он лежит и какой у него бюджет, — в документации своего хоста; готовый блок для вставки — `references/agents-md-bootstrap.md`.

Блок в стартовой инструкции — копия раздела «Правило» этого навыка. При правке обновить оба места, иначе копии разойдутся.

## Файлы
