## Floor — запреты, которые действуют всегда

Не требуют установленного инструмента: проверяются по диффу.

- Новых `@ts-ignore`, `@ts-expect-error`, `eslint-disable`, `# noqa`, `# type: ignore`, `pylint: disable` — без строки-обоснования и записи в исключениях ниже.
- Стабов и глушителей ошибок: `raise NotImplementedError`, `throw new Error("Not implemented")`, пустой `catch`, `except: pass`.
- Удалённых тестов и `.skip`/`xfail`/`it.skip` без причины в сообщении коммита; включённого `.only`.
- Секретов в исходниках, тестах и фикстурах.
- Ослабления самого этого файла, чтобы правка прошла.

## Измерения с числами

Колонка «Чем проверяется» обязательна: число без команды — аспирация.
Команда должна падать при нарушении, а не только печатать отчёт.

| Измерение | Правило | Чем проверяется | Когда гоняется |
|---|---|---|---|
| Типы | ноль ошибок | `tsc --noEmit` | каждое изменение |
| Линт | ноль ошибок и предупреждений | `eslint . --max-warnings 0` | каждое изменение |
| Тесты | ноль падений | `vitest run` | конец задачи |
| Покрытие изменённых строк | ≥ 80% | `vitest run --coverage` плюс `git diff --unified=0` | конец задачи |
| Секреты | ноль находок | `gitleaks dir . --redact --no-banner` | каждое изменение |
| Размер сборки | не больше <N> kB | `npm run size` | конец задачи |

Для Python строки те же: `ruff check .`, `mypy .`, `pytest -q --cov --cov-report=lcov`.
Веб с живым URL добавляет `LCP ≤ 2500` мс, `CLS ≤ 0.1`, `axe` — ноль critical и serious.
CLI, десктоп и iOS вместо этого держат размер артефакта и время отклика команды.

## Как гонять

Одна команда на фазу: проверка не должна зависеть от того, помнит ли агент
последовательность.

- BUILD, после правки, меньше 5 секунд: `make check-fast`
- VERIFY, конец задачи, меньше 90 секунд: `make check`
- REVIEW, перед ревью: `make check && python3 scripts/check_constraints.py`
- SHIP, CI: `make check && gitleaks dir . --redact --no-banner`

Что делает каждая цель, расписывается один раз здесь:

```bash
# Makefile
check-fast:
	ruff check . && mypy .
check:
	ruff check . && mypy . && pytest -q --cov --cov-report=lcov
```

Для TypeScript те же цели: `check-fast` — `tsc --noEmit && eslint . --max-warnings 0`,
`check` — плюс `vitest run --coverage`.
