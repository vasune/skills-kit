## Что где искать по типу

- **Верифицированный сервер** — 1, 10, 11. Источник подтверждён неймспейсом (GitHub/DNS) или создателями протокола.
- **Поиск по каталогу** — 2, 5, 3. Начинать с Glama (крупнейший поиск), mcp.so (больше записей).
- **Курированная подборка** — 4, 13, 14. Редакция или сообщество уже отсеяли мусор.
- **Удалённый запуск без локальной установки** — 3. Smithery хостит серверы.
- **Референтная структура для своего сервера** — 11. Брать эталон кода, не копировать целиком.

## Запросы, которые работают

- `<тема> mcp server` / `<система> mcp` — общий поиск.
- `mcp <система> connector` — по коннекторам к конкретной системе.
- `site:github.com <тема> mcp` — точечно по репозиториям.
- `mcp server <система> npm` — по npm-пакетам.

## Проверка площадки перед записью в базу знаний

```bash
curl -sIL -m 10 -o /dev/null -w '%{http_code}\n' <url>
```

- `200` — ссылка живая.
- `403` у маркетплейса — Cloudflare блокирует скрипт, а не человека: открыть в браузере.
- `429` — rate-limit, не «умер»: открыть браузером позже.
- `000` / таймаут — домен не отвечает из этой сети; пометить в заметке, а не удалять молча.
- Убрать `?utm_source=…` из ссылок перед записью: метки устаревают и тянут лишнее.
