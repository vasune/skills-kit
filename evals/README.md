# Роутинг-эвалы

Зачем: `description` — единственное, по чему агент решает, открыть навык. Смена одной
фразы там меняет срабатывание сильнее любой правки внутри `SKILL.md`. Эвал проверяет
лексикой, без LLM и сети: попадает ли живая фраза в свой навык и уходит ли чужая фраза
владельцу.

## Кейс

`evals/routing/<навык>.json`, имя файла равно `skill`:

```json
{
  "skill": "verification-before-completion",
  "positive": ["готово, можно коммитить?", "тесты прошли, работа готова?"],
  "negative": [{"prompt": "напиши план работ по задаче", "owner": "plan"}],
  "known_miss": "почему провал осознан (необязательно)"
}
```

- `positive` — 5+ фраз, которыми человек реально просит навык: как в чате, с ошибкой,
  с вставленным кодом, по-русски и по-английски, если навык двуязычный. Не «тест 1».
- `negative` — 1–2 фразы чужой задачи: с `owner` обязана попасть в владельца, без
  `owner` — не должна открывать этот навык.
- `known_miss` — признанное ограничение лексического Tier-2 для этого кейса. Его
  провалы печатаются в сводке, но не входят в floor. Ставится только после того, как
  понятно, что описание не починить без потери смысла; не для сокрытия регрессий.

## Запуск

```bash
python3 ./scripts/routing_eval.py              # floor rank-1 90%, top-3, коллизии
python3 ./scripts/routing_eval.py --verbose    # провалы, known_miss, коллизии
python3 ./scripts/routing_eval.py --min-rank1 95 --top 5
python3 ./scripts/routing_eval.py --no-aliases # диагностика без RU↔EN алиасов
```

Токенизация, двуязычный стоп-лист, лёгкий стеммер русских окончаний, TF-IDF по
`name` + `description` (имя с весом ×2), косинус. До TF-IDF доменные слова схлопываются
алиасами RU↔EN (`план↔plan`, `тест↔test`, `коммит↔commit`, `навык↔skill`, …), поэтому
английское описание ловит русский запрос и наоборот; `--no-aliases` показывает, что
даёт одна лексика. Коллизии описаний — порог 0.60: по корпусу максимум 0.51.

## Провал и floor

Провал positive почти всегда значит «в `description` нет слов, которыми пользователь
просит», — чинить описание, а не эвал. Провал negative — описание слишком широкое или
чужая фраза реально ближе: развести триггеры двух навыков.

Floor по умолчанию 90% rank-1 и 100% negative; после починки провалов поднимать
90 → 95 → 100 по факту. Ниже 80 — уже не гейт. Тесты:
`python3 ./scripts/test_routing_eval.py`.
